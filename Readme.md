<h1>RoadMate 🚗 - Web-based Vehicle Rental System</h1>
<h3>What is RoadMate</h3>
<p>RoadMate allows users to browse, book, and rent vehicles online. It connects vehicle owners with renters, enabling seamless booking, secure payments, and real-time availability checking. The system handles user roles, vehicle listings, bookings, and reviews, offering a centralized and automated solution for short-term vehicle rentals.</p>
